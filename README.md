# Curso de C# - CFB Cursos 📚

Repositório dedicado aos códigos, exercícios e projetos desenvolvidos durante o **Curso de C#** ministrado pelo canal [CFB Cursos](https://www.youtube.com/@cfbcursos) no YouTube.

## 🚀 Sobre o Curso
O curso aborda a linguagem C# e o ecossistema .NET, focando desde os conceitos fundamentais da programação orientada a objetos (POO) até o desenvolvimento de aplicações práticas.

## 🛠️ Tópicos Abordados
* Introdução à linguagem e sintaxe básica do C#
* Estruturas de controle e tomada de decisão
* Orientação a Objetos (Classes, Herança, Polimorfismo, Encapsulamento)
* Manipulação de arquivos e coleções
* Introdução a Windows Forms / Banco de Dados (conforme o andamento do curso)

## 💻 Tecnologias Utilizadas
* **Linguagem:** C#
* **Ambiente:** .NET / Visual Studio ou Visual Studio Code
